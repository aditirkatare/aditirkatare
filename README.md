## About

I'm an undergraduate engineering student exploring cybersecurity through hands-on projects in digital forensics, governance, risk and compliance (GRC), and machine learning.

I'm interested in how systems fail, how evidence is validated, and how security controls can be tested and improved.

- **Cybersecurity:** Defensive security and Purple Team fundamentals
- **Digital forensics:** Autopsy, FTK Imager, artifact analysis
- **GRC:** Risk assessment, security policies, control mapping
- **Machine learning:** Model evaluation, leakage checks, validation
- **Languages:** Python, C, C++
